# ИСТОРИК VIDEO FACTORY

Программа для канала «ИСТОРИК», которая делает исторические YouTube-видео от темы до монтажа. Вы выбираете тему, а программа
проходит все этапы:

**исследование → сценарий → промты кадров → кадры → озвучка → материалы → монтаж (ChatCut) → проверка → ГОТОВО.**

После «ГОТОВО» программа останавливается и ждёт вашей команды.

Каждую часть (текст, озвучку, кадры) можно делать разными способами. Если у одного способа кончился лимит или он сломался,
программа сразу берёт следующий и продолжает, а не зависает. Прогресс сохраняется после каждого кадра и каждой части
озвучки, поэтому после сбоя или выключения компьютера работа продолжается с того же места.

## Установка (Windows)

1. Установите Python 3.10+ с python.org и при установке отметьте «Add python.exe to PATH».
2. В папке `istorik_factory` наберите в адресной строке Проводника `cmd` и нажмите Enter.
3. Выполните:
   ```
   py install.py
   ```
   Установщик:
   - ставит пакеты и проверяет, что они импортируются;
   - ставит Chromium (если нет Chrome/Edge), а также Node.js и FFmpeg;
   - **создаёт на месте** `START_ISTORIK.bat` — в папке программы и на рабочем столе;
   - добавляет команду `start istorik`.

   Файлы, созданные на вашем компьютере, Smart App Control не блокирует. Блокирует только скачанные `.bat`.
4. Один раз войдите в Google в профиле программы:
   ```
   .venv\Scripts\python run.py --login
   ```
   Откроется обычный Chrome с профилем ISTORIK. Войдите в аккаунт с подпиской AI Pro, откройте Flow и AI Studio и закройте
   окно. Вход сохранится.

Если запуск начался до окончания установки, программа сама доставит недостающие пакеты (ошибки «No module named 'yaml'»
больше нет). Если доставить не удалось, она покажет настоящую ошибку pip.

## Запуск

Любой из способов:

- двойной щелчок по **`START_ISTORIK.bat`**;
- в новом терминале: **`start istorik`**;
- `python run.py`.

Откроется терминал-пульт, а веб-панель (`http://127.0.0.1:8765`) запустится параллельно:

```
========================================
         ISTORIK VIDEO FACTORY
========================================

1. Актуальные темы
2. Ввести свою тему
3. Продолжить проект
4. Список проектов
5. Настройки
6. Проверка системы
0. Выход
```

Выберите тему и длительность. Дальше программа работает сама и коротко пишет, что делает:

```
▶ 4/8 ГЕНЕРАЦИЯ КАДРОВ
   [14:02:11] Генерирую кадры: 12/48 готово (flow) · 25% · 3:40
   · ollama qwen3:4b: 843 ток., 11.8 ток/с, 1:12
   ⚠ Кадры: Google Flow — лимит подписки на сегодня. Переключаюсь на «Pollinations»
```

Полные подробности пишутся в папку `logs/`. Чтобы видеть их и в терминале, запустите с `--debug` или напишите `debug`.

Другие режимы запуска:

- `python run.py --panel` — только веб-панель;
- `python run.py --topic "Тема" --minutes 5` — полностью автоматически, без меню.

## Команды (в любой момент)

| Команда | Что делает |
|---|---|
| `стоп` | Останавливает работу: текущая операция доделывается, прогресс сохраняется. Процесс не убивается |
| `пауза` / `продолжить` | Приостанавливает работу в ближайшей безопасной точке и продолжает её |
| `статус` | Показывает этап, текущее действие, прогресс, время и источники, которые работают сейчас |
| `темы` · `проекты` | Список тем и список проектов |
| `продолжить <номер или id>` | Продолжает остановленный проект с последнего незавершённого шага |
| `режим фон\|экран\|гибрид [текст\|озвучка\|кадры]` | Выбирает, как работать (см. «Режимы») |
| `flow да\|нет` | Отмечает, что у вас есть Google AI Pro и доступ к Flow. После этого Flow становится первым источником кадров |
| `экран согласен` / `экран выключить` | Включает или выключает экранный режим (сначала прочитайте предупреждение) |
| `ключи` | Добавляет ключи Gemini (необязательно) |
| `debug` · `помощь` · `выход` | Подробные ошибки, список команд, выход (с безопасной остановкой) |

Если нужен человек (вход в Google, CAPTCHA, подтверждение «это вы»), программа останавливается и пишет:

```
========================================
          ТРЕБУЕТСЯ ДЕЙСТВИЕ
========================================
Google Flow: войдите в свой аккаунт Google в окне браузера ISTORIK…

После этого напишите:  продолжить
```

## Режимы

Режим задаётся отдельно для текста, озвучки и кадров: в панели («Источники») или командой `режим`.

| Режим | Как работает |
|---|---|
| **Фон** | Только API и программы на компьютере (Gemini API, Ollama, Piper). Экран не используется |
| **Экран** | Сначала — ваш браузер на экране: Gemini в Chrome, AI Studio (голос Sadaltager), Flow, ChatCut. Остальные источники — запасные |
| **Гибрид** (по умолчанию) | В фоне, а когда кончился лимит или источник упал — автоматически через экран |

Экранный режим для Gemini и AI Studio по умолчанию **выключен** и включается один раз, после предупреждения.

> **Внимание.** Экранный режим управляет вашим браузером, как это делали бы вы. Это медленнее API и, вероятно, нарушает
> правила Google об автоматическом доступе к сервисам. Аккаунт, в том числе с подпиской, могут ограничить. Программа
> работает человеческим темпом (не чаще одного запроса в 20 секунд), ничего не обходит, не прячет автоматизацию и
> останавливается на любой проверке.
>
> Основной путь — официальные API и программы на компьютере. Flow работает только через браузер: у него нет API для картинок.

## Источники

Пометки: **∞ локально** — без квот, но ограничено железом · **🔑 ключ** — API с дневной квотой · **⭐ подписка** ·
**🖥 экран** — ваш браузер · **бесплатно** — онлайн-сервис с очередью · **⚠ неофициально** · **— пропустить**.

| Часть | Источник | Пометка | Нужно | Заметки |
|---|---|---|---|---|
| Текст | Gemini API | 🔑 | ключи AI Studio | Лучший русский текст, поиск Google. Тратится только там, где нужен (см. «Экономия Gemini») |
| Текст | Groq / OpenRouter / Mistral / Cerebras | 🔑 | бесплатные ключи | Без ключа **молча пропускаются** и не засоряют ошибки |
| Текст | **Ollama** | ∞ локально | Ollama + модель | Берётся **лучшая установленная** модель; на 4 ГБ — `qwen3:4b` |
| Текст | Gemini в Chrome | 🖥 экран | вход в Google | Новый чат на каждый запрос, ответ забирается целиком |
| Озвучка | Gemini TTS (Sadaltager) | 🔑 | ключи | Пока есть квота |
| Озвучка | **AI Studio в Chrome** (Sadaltager) | 🖥 экран | вход в Google | Generate speech по частям. Каждая часть проверяется; плохая переделывается отдельно |
| Озвучка | **Piper** | ∞ локально | `ru_RU-denis-medium` | Надёжный запасной вариант. Если Hugging Face недоступен, голос скачивается с GitHub |
| Озвучка | Silero / Chatterbox | ∞ локально | torch | На Windows без длинных путей torch не ставится, поэтому Silero не рекомендуется (см. «Если что-то не работает») |
| Озвучка | Edge TTS | ⚠ | edge-tts | Только если выберете сами |
| Кадры | **Google Flow** | ⭐ + 🖥 | подписка AI Pro | Основной источник, если отмечено `flow да`. По одному кадру, ≈20–60 с |
| Кадры | Gemini API | 🔑 | ключи | У бесплатных ключей квота на картинки часто нулевая |
| Кадры | Pollinations | бесплатно | — | ≈1 кадр в 15 с |
| Кадры | ComfyUI (FLUX/SDXL) | ∞ локально | NVIDIA от 8 ГБ | На 4 ГБ практически бесполезно (минуты на кадр) — не рекомендуется |
| Любая | **Свои файлы** | — | — | Картинки из `04_images/import/001.png…`, озвучка из `05_voice/import/` (по частям `voice_001.wav…` или **одним файлом** на весь текст — он режется по паузам) |
| Озвучка/кадры | Нет | — пропустить | — | Только если выбрать осознанно: тишина по темпу речи / титульные карточки. В отчёте это отмечено |

### Как переключаются источники (fallback)

Каждый вызов идёт по цепочке. Результат зависит от того, что случилось:

- **нет ключа или не установлено** — источник молча пропускается;
- **квота (429)** — источник пропускается до сброса лимита (время сброса видно в «Лимитах»), работа сразу идёт дальше;
- **ключ не принят (401/403)** — источник отключается на 6 часов;
- **таймаут или обрыв** — источник пропускается на 2 минуты;
- **испорченный ответ** — запрос повторяется у следующего источника, а этот источник не штрафуется;
- **нужен человек** (вход, CAPTCHA) — пауза до команды `продолжить`;
- **все источники недоступны** — понятная ошибка с временем ближайшего сброса. Проект можно продолжить позже с того же места.

Ошибка всегда называет настоящий источник: «Ollama (qwen3:4b) молчит дольше 90 с», а не «Gemini не ответил».

### Ollama на слабой видеокарте (RTX 2050, 4 ГБ)

- **Модель.** Берётся только реально установленная (`/api/tags`). Если в настройках стоит `qwen3:8b`, а установлена
  `qwen3:4b`, будет `qwen3:4b` с предупреждением.
- **Контекст.** Подбирается под видеопамять: на 4 ГБ — 4096–8192, а не 16384, при котором модель уходила в ОЗУ. Если
  запросу нужно больше, контекст увеличивается ровно настолько, насколько нужно.
- **Ответ потоком.** В терминале и панели видно число токенов, скорость и время. Любая «тишина» ограничена по времени.
- **Потоки.** Один запрос за раз. Менеджер ресурсов не держит Ollama и ComfyUI в видеопамяти одновременно.
- **Выбор модели.** `qwen3:4b` — лучший JSON среди маленьких моделей, `gemma3:4b` — живее русская проза. Обе помещаются
  в 4 ГБ. Сравнить их на вашем ПК: `python run.py --smoke mypc`.

### Поиск тем

1. Годовщины ближайших недель по нише канала из Википедии («В этот день») — без ключей и без Gemini.
2. Ваш канал и конкуренты на YouTube (RSS, или API при наличии ключа).
3. ИИ из цепочки текста. Для локальной модели используется короткий промт и простая схема.
4. Если ИИ недоступен, показываются темы из списка канала (`channel/profile.yaml → topic_bank`) без уже сделанных.
   **Темы есть всегда.**

Время поиска ограничено: облако — 90 с, Ollama и экран — `topics.local_max_seconds` (600 с). Результат кэшируется.

### Экономия Gemini

- Ключи **не проверяются** при каждом старте. Раньше это тратило время и квоту, теперь проверка — только по кнопке «Проверить ключи».
- «Сверка сценария» моделью pro выполняется только при основном Gemini API и для роликов от 10 минут.
- Кэш:
  - ответы моделей — 30 дней;
  - темы — 12 часов;
  - годовщины — 30 дней;
  - факты из Википедии — 7 дней.
- **Ключи одного проекта Google делят один лимит.** Если у ключа 429, для этой модели пропускаются и остальные ключи того же
  проекта. Число ключей не раздувается ради обхода квот. Проект подписывается у ключа в окне «Ключи», а если Google назвал
  проект в ответе — подпись ставится автоматически.

### Рекомендации не затирают ваш выбор

Кнопка «Рекомендовать» подбирает цепочки под видеокарту, ОЗУ, установленные программы, подписку и ключи. Если вы
настраивали часть вручную, рекомендация только **добавляет** запасные источники в конец. Flow при отмеченной подписке
всегда остаётся первым.

## Вход в аккаунты — один раз руками

- **Google (Flow, AI Studio, Gemini)** — `python run.py --login`. Откроется обычный Chrome с профилем программы, войдите в
  нём. Чтобы работать в своём Chrome, запустите его с `--remote-debugging-port=9222` на отдельном профиле и укажите
  `chrome_cdp_url` в `data/settings.json`. Свой основной Chrome программа не закрывает.
- **ChatCut** — вход по OAuth в окне браузера при первом монтаже. Токен хранится в `data/chatcut_oauth.json`, он не
  попадает в git.

## Монтаж (ChatCut)

1. **ChatCut MCP** — полный монтаж:
   - проект с названием темы;
   - загрузка озвучки и кадров, кадры по таймкодам речи;
   - движение и переходы, главы, заставка, имена и даты;
   - субтитры, звуки, выравнивание громкости.

   Повторный запуск ничего не загружает второй раз.
2. **Окно ChatCut в браузере** — если MCP недоступен и включён экранный режим.
3. **Локальная сборка** — если ChatCut недоступен. Готовое MP4 собирается ffmpeg по тем же таймкодам, а монтажный план
   сохраняется в `06_edit/edit_plan.json` и `chatcut_brief.md`. В финале честно написано
   «Монтаж: ChatCut НЕ выполнен — …». Ложного «смонтировано в ChatCut» не бывает.

## Остановка, пауза, продолжение

- После каждого подзадания сохраняются:
  - `project.json` — всё состояние;
  - `state.json` — кратко: этап и что уже готово;
  - `manifest.json` — все материалы с размерами и контрольными суммами.
- `стоп` или выключение компьютера: после запуска `продолжить <проект>` продолжает с незавершённого кадра или части
  озвучки. Готовое не переделывается.
- Контроль качества перед переходом к следующему этапу:
  - **сценарий:** по-русски, достаточная длина, без повторов, есть начало и финал;
  - **кадры:** все номера, читаемость, размер, без чёрных и одинаковых;
  - **озвучка:** не тишина, длительность, порядок.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| Панель пустая | Панель сама переподключается («Подключаюсь к программе… попытка N»). Если сервер закрыт, запустите `START_ISTORIK.bat` |
| «Ollama не запущена» | Откройте приложение Ollama. Программа тоже пытается запустить её сама |
| Silero: «Windows Long Path support» | Используйте Piper (он уже работает). Если Silero всё же нужен: PowerShell от администратора → `New-ItemProperty -Path HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem -Name LongPathsEnabled -Value 1 -PropertyType DWORD -Force`, перезагрузка, затем «Установить» |
| Flow просит вход | `python run.py --login`, войдите, затем `продолжить` |
| Сайт изменил вёрстку | Скриншот сохраняется в `logs/browser/`, работа идёт через следующий источник |
| Все источники в лимите | Ошибка покажет время сброса. Добавьте локальный источник (Ollama/Piper) или продолжите позже |
| Подробности ошибок | `logs/errors.log`, `logs/providers.log`, `logs/browser.log`, журналы проекта в `08_logs/` |
