# ИСТОРИК VIDEO FACTORY

Локальный автономный конвейер производства исторических YouTube-видео для канала «ИСТОРИК».
Выбираете тему → программа сама делает исследование, сценарий, промты, кадры (Google Flow), озвучку (Gemini TTS,
голос Sadaltager), монтаж в ChatCut, проверку и экспорт → в конце пишет **ГОТОВО**.
Работает без Claude: нужен только ваш компьютер, API-ключ Google AI Studio и однократный вход в Google и ChatCut.

## Быстрый старт (Windows)

1. Установите Python 3.10+ (python.org, галочка «Add to PATH»).
2. Дважды щёлкните `setup.bat` — установит зависимости, браузер Playwright, Node.js и FFmpeg (через winget).
3. Дважды щёлкните `ISTORIK_VIDEO_FACTORY.bat`.
   При первом запуске терминал спросит `Google AI Studio API key` (и, по желанию, YouTube API key) — ключи сохранятся в `.env`.
4. Откроется панель `http://127.0.0.1:8765`: актуальные темы → **ВЫБРАТЬ ТЕМУ**. Дальше всё автоматически.

macOS/Linux: `./setup.sh`, затем `./istorik.sh`.

## Что нужно сделать вручную (один раз)

| Когда | Что | Как программа об этом скажет |
|---|---|---|
| Первый запуск | Ввести API-ключ Google AI Studio | вопрос в терминале или поле в панели |
| Первая генерация кадров | Войти в Google в окне браузера, которое открыла программа (Flow) | окно «ТРЕБУЕТСЯ ДЕЙСТВИЕ ПОЛЬЗОВАТЕЛЯ» → «Продолжить» |
| Первый монтаж | Войти в ChatCut и разрешить доступ «ISTORIK VIDEO FACTORY» | откроется страница входа ChatCut, дальше само |

Вход сохраняется (профиль браузера `browser_profile/`, токены ChatCut `data/chatcut_oauth.json`), повторно не нужен.
CAPTCHA/подтверждения — тот же механизм: программа остановится, покажет, что сделать, и продолжит после «Продолжить».

## Этапы и файлы проекта

```
projects/2026-09-30_<slug-темы>/
  project.json            состояние: этапы, прогресс, ошибки, ссылки (сохраняется после каждого действия)
  01_research/            research.md, research.json (хронология, личности, войны, спорные моменты, источники)
  02_script/              script.txt, script.json (предложения: глава, текст, визуал, персонажи, даты)
  03_prompts/             frames.json, prompts.txt (кадр 001… ↔ предложения ↔ промт)
  04_images/              001.png, 002.png … (сбой → 014_FAILED, после повтора → 014.png)
  05_voice/               voice_001.wav … master_voice.wav, voice_timings.json (таймкоды частей/кадров/предложений)
  06_edit/                assets.json, edit_plan.json (монтажный план), subtitles.srt, chatcut_brief.md
  07_export/              <id>.mp4 (экспорт ChatCut), <id>_preview.mp4 (локальный рендер), REPORT.txt, checks.json
  08_logs/                pipeline.log, flow.log, voice.log, cut.log, errors.log …
```

| Этап | Как работает |
|---|---|
| Темы | YouTube Data API/RSS (ваш канал, конкуренты, свежие ролики ниши) + поиск Google через Gemini; исключает уже сделанные темы (`channel/profile.yaml → published_topics`, пополняется автоматически) |
| Исследование | 4 независимых поисковых прохода (хронология, личности/войны, спорные моменты, визуальный мир) + сверка в JSON |
| Сценарий | план → главы по одной (без повторов, с мостиками) → разбивка на предложения → разметка визуала; структура канала из `channel/profile.yaml` |
| Промты | ~1 кадр на 15 слов (в хуке — на 8), библия персонажей для единообразия, промты по 20 кадров |
| Кадры | Google Flow через браузер (у Flow нет публичного API); по одному промту, проверка файла, повтор, круги повторов в конце; запасной генератор — Gemini API (Imagen) |
| Озвучка | Gemini TTS, голос Sadaltager, стиль friendly + дикторская установка; части ≤900 символов по целым кадрам; проверка каждой части; склейка, −16 LUFS |
| Монтаж | ChatCut через его официальный MCP-интерфейс (тот же, что у плагина ChatCut для Claude/Codex): новый проект с названием темы, загрузка, V1 кадры по таймкодам речи, zoom push/pull, переходы (cross-dissolve / dip-to-black на главах / flash на кульминациях / whip-pan и др. в хуке), Hook Punch, Title Reveal, Chapter Card, Name Title, Date Stamp (шаблоны из вашего проекта-примера), звуки, субтитры Montserrat 800, smooth_audio. Таймкоды уточняются по транскрипту ChatCut |
| Проверка | аудио (порядок, повторы, паузы, громкость, конец = конец видео), кадры (номера, битые/чёрные, дубли, смысл — выборочно моделью со зрением), монтаж (промежутки, наложения, движения, переходы), субтитры, таймлайн ChatCut, превью начала/середины/конца; экспорт из ChatCut + локальный рендер |

## Возобновление

Каждое действие сохраняется. После сбоя/перезагрузки откройте панель → «Проекты» → **Продолжить** —
работа продолжится с незавершённого шага (например, с кадра 83 из 120). Из терминала:

```
python run.py --list
python run.py --resume 2026-09-30_vsya-istoriya-...
python run.py --resume <id> --from-stage voice      # принудительно переделать с этапа
python run.py --topic "Вся история Казахского ханства" --minutes 15   # FULL AUTO без панели
```

## Настройки

`config.yaml` — разрешение/fps, модели, темп речи, кадры на слова, голос, размер частей озвучки, переходы, звуки, субтитры, ChatCut.
`channel/profile.yaml` — ниша, стиль сценария, визуальный стиль, конкуренты (`@handle` или `UC…`), ваш канал, опубликованные темы.
`.env` — ключи (`.env.example` — описание). `.env` в `.gitignore`.

Если ChatCut недоступен через MCP, включается запасной путь: браузер открывает ChatCut, загружает файлы и передаёт встроенному
агенту ChatCut ТЗ `06_edit/chatcut_brief.md`. Локальный рендер (`07_export/*_preview.mp4`) делается всегда.
